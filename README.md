# Adriana Salgados para Festas

Landing page premium e moderna desenvolvida para uma empresa especializada em salgados artesanais para festas, aniversários, casamentos, confraternizações e eventos corporativos.

O projeto possui visual sofisticado inspirado em startups gastronômicas premium como iFood, Rappi e buffets gourmet.

---

# Instalação

Clone o projeto:

```bash
git clone https://github.com/seuusuario/adriana-salgados.git
```

Entre na pasta:

```bash
cd adriana-salgados
```festas-e-salgados/

# Personalização

Você pode alterar:

* Imagens em:

```bash
src/assets/
```

* Produtos:

```bash
src/components/Produtos.jsx
```

* Informações de contato:

```bash
src/components/Footer.jsx
```

* Hero principal:

```bash
src/components/Hero.jsx
```
